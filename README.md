# 💍 Invitación de Boda Mágica - El Juego

Proyecto de invitación interactiva creada con **Phaser 3** para nuestra boda el 04.07.2026.

## 🚀 Enlace al juego
Puedes ver la invitación funcionando aquí: https://invitacion-boda-jorge-conxy.netlify.app/
## 📝 Características
- Juego de plataformas interactivo.
- Selección de personaje (Novio/Novia).
- Integración con Google Forms para confirmación de asistencia.
- Integración con Google Maps para localización del evento.

## 🛠️ Tecnologías utilizadas
- Phaser 3 (Motor de juegos JS)
- HTML5 / CSS3
- Google Fonts (Cinzel Decorative & Eagle Lake)
